# Pygame Application

Приложение на Python с использованием библиотеки Pygame, предоставляющее графический интерфейс с различными UI-элементами.

## Описание

Это приложение демонстрирует создание пользовательского интерфейса с помощью Pygame, включая:

- Окно приложения без рамок (frameless window)
- Поле ввода текста (TextInput)
- Текстовое поле с прокруткой (TextField)
- Вертикальные и горизонтальные полосы прокрутки (Scrollbar)
- Ленту кнопок (ButtonRibbon)
- Кнопку Copy DNA
- Контекстное меню
- Чекбоксы и другие элементы управления

## Требования

- Python 3.x
- Pygame

## Установка

1. Установите зависимости:
```bash
pip install pygame
```

2. Запустите приложение:
```bash
python main.py
```

## Управление

- **ESC** - Закрыть приложение
- **Мышь** - Взаимодействие с элементами интерфейса
- **Колесо мыши** - Прокрутка содержимого

## Элементы интерфейса

### Основное окно
- Размер: 1440x900 пикселей
- Безрамочный режим (pygame.NOFRAME)
- Кнопки закрытия и сворачивания

### Поисковая панель
- Надпись "SEARCH"
- Поле ввода текста
- Вертикальная полоса прокрутки для результатов

### Лента кнопок
- Горизонтальная лента с категориями:
  - VITALS, BODY, SHOES/GEAR, ACCESSORIES, ATTRIBUTES
  - TENDENCIES, HOT ZONES, SIGNATURE, CONTRACT, BADGES
- Горизонтальная полоса прокрутки

### Кнопка Copy DNA
- Расположена в правом нижнем углу
- Копирование данных при нажатии

## Настройка

Все константы вынесены в файл `constants.py`:
- Размеры окна и элементов
- Цвета (COLOR_BLACK, COLOR_WHITE, COLOR_GRAY)
- Шрифты (Calibri, различные размеры)
- Позиции элементов
- Отступы и маргины

## Расширение функциональности

Для добавления новых элементов:
1. Создайте класс в папке `classes/`, наследуясь от `BaseElement`
2. Реализуйте методы `update()` и `draw()`
3. Добавьте экземпляр в главное окно через `app_window.add_child()`

## Лицензия

Проект создан для демонстрации возможностей Pygame.
